# PageMind AI Chrome Extension

## Features
- Summarize any webpage
- Extract key points
- Generate social media posts
- Freemium model (10 free/day)

## Setup
1. Load unpacked in Chrome (`chrome://extensions`)
2. Users provide their own AI API key (OpenAI-compatible) for free tier, or you proxy via backend for paid.
3. Monetize via upgrade button linking to Stripe/LemonSqueezy/Gumroad ($5-9/mo unlimited).

## Deployment
- Package as .zip and submit to Chrome Web Store.
- For higher conversion: use a backend (Vercel + Supabase/Stripe) to manage keys and usage.

## AI Sustainment
An AI agent can monitor usage metrics, update prompts, generate marketing copy, and handle support tickets.
